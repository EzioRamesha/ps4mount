No PS4 games found. Copy the .pkg files (game, update and add-ons) to a USB drive, in any folder.

Settings

Every folder of every drive is searched for pkgs, which are used where they are.
For a game on one drive with its update or add-ons on another. Keep both drives connected: without the other drive, the game is added again without them.
Restore games to the original path Moves the pkgs of a game (game, update and all its add-ons) back to where they came from, with their original names, and takes the game out of the library. No pkg is deleted. The open game is closed first.

Restore selected games

Each selected game is moved back with its update and all its add-ons (DLC). The open game is closed first.
